# Focustcast Streamdeck

An Elgato Streamdeck's plugin to connect and interact with your local focuscast instance

## Installation

### Official

Once available, you'll be able to download from the elgato marketplace.

### Build it yourself

If you don't want to go through the marketplace and want to do it yourself, here's how:

- clone this repo
- install dependencies with pnpm install
- run the watch command with pnpm watch. This will bundle the code and install it as a local extension in your streamdeck
